- The Hub's GitHub browser login now uses PKCE (S256): as defence-in-depth to bind the authorization code to the browser that started the login, the authorize redirect carries a `code_challenge`, the matching `code_verifier` lives in a short-lived single-use HttpOnly cookie, and the token exchange is a form-encoded POST carrying it, so client secret, code and verifier no longer appear in the request URL. A callback with a missing or malformed verifier is rejected with 400 before any code exchange or session is minted; logins started before the upgrade must be restarted (#14633).
